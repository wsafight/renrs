# Story Project

Run `renrs-check .`, then `renrs .`. Audio starts muted.

- Edit `script.rns`; running directory projects reload scripts and resources.
- Keep `config id` stable after publishing.
- Choose a language in the player's settings.
- Run `renrs-debug test . routes.json` to verify both endings.
- Run `renrs-build . dist/game` to create a player and archive.
- Set `renrs.toolsPath` in VS Code when the RenRS tools are not on PATH.

The sample images were generated for RenRS and are distributed under MIT.
